# Calculadora básica
🎯 Objetivos

* Desarrollar una calculadora básica en Kotlin con entrada de datos por consola.
* Diseñar un menú interactivo con las opciones de sumar, restar, multiplicar, dividir, calcular el resto y salir.
* Gestionar la opción elegida mediante la estructura de selección `when`.
* Utilizar variables de tipo numérico (`Double`) para permitir operaciones con decimales.
* Permitir realizar varias operaciones seguidas, repitiendo el menú hasta que el usuario decida salir.

🛠️ Tecnologías
* Kotlin
* IntelliJ IDEA
* Git y GitHub

📋 Requisitos del Proyecto

* Proyecto de tipo aplicación de consola, con nombre `UD01_Actividad03_Calculadora`.
* Usar la estructura `when` para evaluar la opción del menú.
* Repetir el menú con una estructura `do-while` o `while`.
* Validar que la opción seleccionada exista.
* No permitir la división entre cero.
* No calcular el resto si el segundo número es cero.
* Mostrar mensajes de error comprensibles para el usuario.
